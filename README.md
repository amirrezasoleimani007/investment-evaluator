# داشبورد مالی IPS

سامانه فارسی تحلیل و رتبه‌بندی عملکرد مالی شرکت‌ها با ورودی Excel.

## قابلیت‌ها

- خواندن مستقیم فایل‌های Excel آتیه فولاد و فولاد متیل در مرورگر
- امتیازدهی شش‌بُعدی بر پایه ۱۳ شاخص مالی
- کنترل پوشش داده و تفکیک رتبه رسمی، موقت و ناکافی
- رتبه‌بندی Dense بر پایه امتیاز گردنشده
- تحلیل روند، مقایسه شرکت‌ها، کنترل کیفیت داده و خروجی Excel

## اجرای محلی

```bash
npm ci
npm run dev
```

## ساخت نسخه عمومی

```bash
npm run build:pages
```

انتشار عمومی به‌صورت خودکار از شاخه `ips-dashboard` توسط GitHub Pages انجام می‌شود.
