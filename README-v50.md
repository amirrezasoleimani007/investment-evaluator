# سامانه تحلیل مالی و راهبری سرمایه آتیه — نسخه ۵۰

نسخه مستقل با صفحه آغاز متحرک، میزکار مدیریتی، منوی کناری، ورود گروهی اکسل و رابط فارسی راست‌به‌چپ.

## اجرا

[اجرای آنلاین](https://amirrezasoleimani007.github.io/investment-evaluator/)

برای اجرای محلی، `Atieh50.html` را در مرورگر باز کنید. فایل‌های مالی و تکمیلی را از صفحه «پرونده و داده‌ها» انتخاب کنید. اطلاعات اکسل در مرورگر پردازش می‌شود. فایل داده مالی یا پرونده پشتیبان نمونه همراه انتشار قرار نگرفته است.

## سورس و ساخت

[دانلود سورس کامل نسخه ۵۰](https://github.com/amirrezasoleimani007/investment-evaluator/raw/refs/heads/ips-dashboard/releases/v50/Atieh50-Source.zip)

پس از استخراج سورس:

```
node build-v50.cjs
node --check v50-check.mjs
node test-v50.cjs
```

فایل مبنا `Atieh49.html` است. رابط خوانا در `v50-components.js` و `v50.css` نگه‌داری می‌شود. اسکریپت ساخت هر تغییر را با تطبیق یکتا کنترل می‌کند؛ خروجی مستقل در `Atieh50.html` نوشته می‌شود.

## تغییرات اصلی

- آغاز گرافیکی با موشن، پشتیبانی از کاهش حرکت و ترجیح ورود مستقیم.
- نمای مدیریتی با پوشش واقعی پرونده فعال و دسترسی به تحلیل‌ها.
- منوی ثابت دسکتاپ و منوی بازشونده موبایل.
- نمایش جزئیات سیاست و وزن‌دهی در بخش‌های بازشونده.
- بهبود جدول‌ها، نمایش درصد، توضیح جامعه رتبه و هماهنگی دوره نقشه سرمایه.
- اعتبارسنجی مقصد فایل مالی و نمایش نمونه شرکت‌ها پیش از ورود.
- ذخیره و بازیابی مرزهای نامحدود تنظیمات بدون تغییر مقدار.

کنترل نحوی، آزمون‌های حفظ هسته محاسبات و کتابچه قواعد، نمایش عدد، پایه منفی/صفر و سریال‌سازی تنظیمات اجرا شده‌اند. مسیرهای اصلی رابط، ورود داده، ذخیره و بازیابی و نمای باریک مرورگر نیز بررسی شده‌اند. این انتشار، ممیزی مستقل تمام فرمول‌ها و خروجی‌های چاپی نیست.

نسخه‌های قبلی در تاریخچه Git مخزن حفظ شده‌اند. پوشه‌های سایر برنامه‌های این مخزن مستقل‌اند.
